# joeyalvarado.dev

Personal portfolio and build-notes site for Joey Alvarado.

The minimalist information architecture and visual direction are adapted from [Astro Nano](https://github.com/markhorn-dev/astro-nano), licensed under MIT.

## Stack

- Astro 7
- TypeScript
- Astro view transitions
- Vercel

## Commands

```bash
npm install
npm run dev
npm run build
```
